# Harpy: All-in-one App Manager
## Multi-Machine, Multi-OS

Ever got tired of switching to a new machine and having to remember all your previous apps? Harpy solves it. TUI (terminal-based interface), with a single command you can run it, select all wanted apps and install them immediately!

- Parallel Downloads
- Beautiful interface
- Fuzzy searching
- Auto-installs: Never lose time clicking buttons when the All-Knowing-Machine can do it for you!
